# BGS - Frontend

Application Angular du site **BoardGameShop**. Voir le [README principal](../README.md) pour la vue d'ensemble du projet.

## Commandes utiles

```bash
npm start          # serveur de développement (http://localhost:4200)
npm run build       # build de production dans dist/frontend
npm test            # tests unitaires (Karma)
```

L'application attend l'API backend sur `http://localhost:8080/api` en développement
(voir `src/environments/environment.development.ts`).
